# Approved blue authentication artwork

These separate RGBA PNGs were extracted with the built-in image-editing tool
from the user-approved screen references. The user selected reference extraction;
the app renders all text, dots, inputs, navigation and actions independently.

| Asset | Reference | Dimensions |
| --- | --- | --- |
| `auth-login-hero.png` | D, `Downloads/login screen.png` | 1536 × 1024 |
| `auth-register-hero.png` | E, `Downloads/step 1.png` | 1536 × 1024 |
| `auth-details-hero.png` | F, `Downloads/step 2.png` | 1536 × 1024 |

Each edit isolated only the approved parent, white baby seal, book or lock,
and floating blue artwork. The prompts required the original appearance,
expression, proportions, pose, composition and glossy rendering, without new
characters or symbols. Screen text, controls and the page background were
removed, requesting genuine transparent alpha and modest clear margins.

The first two paths retain existing startup-preload references; the third is
preloaded alongside them. All three images have explicit proportional render
dimensions so React Native Web does not use their intrinsic canvas height.
