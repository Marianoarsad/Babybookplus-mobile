# Sharing-only artwork

Transparent foreground PNG assets derived from the approved `Choose Records to Share Interface.png` reference using the built-in image editing workflow on 23 October 2026. Each edit requested only the matching baby head, paired green leaves or green apple, without the screenshot, labels, controls or circular badge. The sharing component supplies its badge independently.

These assets are local to the sharing permission grid. They do not redefine the global record-category registry, allergy artwork, baby avatars or navigation icons. Retain transparency and aspect ratio.
